How performance tracking works

Individual holding gain/loss uses current price, share count, and your entered cost basis. For whole-portfolio performance, you can enter net outside contributions since the previous snapshot (deposits minus withdrawals). The app then estimates investment-only change for that period, rather than mistaking deposits for gains. It does not calculate a precise annualized return or account for transaction timing.

Privacy & technical notes

This is a static app designed for GitHub Pages. Your holdings, balances, FIRE settings, snapshots, and optional API key are stored in your browser's local storage, not uploaded to a dashboard server. If you choose to refresh prices, your browser sends ticker symbols and your API key to Finnhub. Do not commit your API key to GitHub. Browser storage is not encrypted and should not be treated as secure for shared devices. The app uses no analytics or tracking scripts.

Funds without public market symbols, private assets, and cash can be tracked manually. Market prices must be verified independently before financial decisions.
